# Xbrain - 跨学科知识脑图库

一个由 AI 智能体维护的跨学科知识体系脑图库，使用 XMind 格式组织知识。

## 目录结构

```
Xbrain/
├── README.md           # 本说明文件
├── Xbrain.xmind        # 知识体系总览脑图
├── 哲学/               # 哲学类脑图
├── 科技/               # 科技类脑图
├── 数理化/             # 数学、物理、化学类脑图
└── 神学/               # 神学类脑图
```

## 知识体系框架

根节点：**我的知识体系**

一级学科节点：
- 哲学
- 科技
- 数理化
- 神学

## 工作流

1. 用户提供学习内容或知识整理需求
2. 智能体通过 XMind 生成/更新对应脑图（.xmind 文件）
3. 每次变更自动执行 `git add` / `git commit` / `git push` 同步到 GitHub
